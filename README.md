# Wärtsilä ESG & Circular Economy Prototype

This project is a prototype website that demonstrates how AI can support ESG (Environmental, Social, Governance) reporting. The prototype is based on Wärtsilä’s publicly available sustainability information and annual report.

## Project Idea

The goal of this project is to show how complex sustainability data can be simplified into a clear and visual format. Instead of reading long ESG reports, users can view key insights through summaries and a dashboard.

## Features

* ESG summary divided into Environmental, Social and Governance categories
* Circular economy explanation based on Wärtsilä’s lifecycle approach
* AI-assisted summary of sustainability information
* Visual dashboard with key indicators and targets
* Simple flow showing how ESG reports can be transformed into dashboards using AI

## How AI is Used

AI was used to summarise Wärtsilä’s sustainability content into key themes and insights. In a real-world application, AI could:

* Analyse large ESG reports automatically
* Extract key performance indicators (KPIs)
* Detect trends and changes over time
* Update dashboards dynamically
